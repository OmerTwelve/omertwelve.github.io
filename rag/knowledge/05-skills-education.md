# Skills and Education

## Programming languages Omer knows

Python, SQL, C++, C and C#. Python is his primary language for machine learning
and backend work; SQL for relational database design.

## Frameworks and libraries Omer works with

PyTorch, TensorFlow, scikit-learn, Pandas, NumPy, Matplotlib, React and FAISS.
He has used PyTorch for transformer fine-tuning and CNN work, scikit-learn for
the classical models deployed in NeuroSense, NumPy and SciPy for digital signal
processing, and FAISS for semantic vector search.

## Tools and platforms Omer uses

FastAPI, Docker, Git, REST APIs, Streamlit, Supabase, Arduino, and Cloudflare
Workers. He has deployed FastAPI services on a self-hosted Linux server with
systemd and Cloudflare tunnels in production.

## Omer's education

Omer holds a BSc in Artificial Intelligence Engineering with Honours from
Cyprus International University in Nicosia, Cyprus. His concentrations were
Machine Learning, Data Science, Natural Language Processing, and Signal and
Image Processing. His related coursework covered Database Management, Embedded
Systems, and Robotics and IoT.

## What Omer's experience adds up to

Across his work there is a consistent pattern: systems that run rather than
notebooks that demonstrate. NeuroSense reads live hardware and serves live
inference. The Alemdar Teknik dashboard ran in production for company staff on
self-hosted infrastructure. AI Therapist shipped as a working retrieval and
classification pipeline. He also pays attention to the failure modes that do
not announce themselves — silent model drift, wrong sample rates, mislabelled
channels, prompt injection — and documents them rather than patching over them.
