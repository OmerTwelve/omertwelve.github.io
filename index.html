NeuroSense — Real-Time EEG Stress Classification

A full brain–computer interface: raw 8-channel scalp voltages off an OpenBCI Cyton, streamed at 250 Hz through a stateful DSP pipeline into both a classical stress index and a trained classifier, rendered live in a React dashboard.

  • Random Forest over 40 band-power features with per-subject baseline normalization — 80.5% leave-one-subject-out accuracy across 36 subjects, beating both logistic regression and an EEGNet CNN.
  • Parsed the WiFi shield’s raw binary EEG packets directly over TCP, then filtered, rejected artifacts, and computed spectra continuously without losing stream state.
  • Prevented silent model drift by sharing one feature-extraction module between training and live inference, with feature order locked into the saved model metadata.
